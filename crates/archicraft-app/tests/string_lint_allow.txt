# String literals the literal-string lint (string_lint.rs) reports that are
# not user-interface text (NFR-L10N-001). One entry per line:
#
#   <scope> | "<literal>" | <reason>
#   <scope> | * | <reason>
#
# <scope> is a file relative to the repository root, optionally followed by
# ::<item> (for example ::Dialogs::about_window) to cover one item only.
# <literal> is written as Rust prints it with {:?}; * covers every literal in
# the scope. Every entry needs a reason, and an entry that no longer matches
# a literal fails the lint.
