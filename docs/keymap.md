# Default keymap

The default keyboard shortcuts of ArchiCraft (UI-008, HW-003). Appendix D.8 of the SRS names the
commands that need one and leaves the keys to the UI design; this page is that design. The tables
below are generated from the command registry (`crates/archicraft-app/src/commands/`), the D.8
table (`commands/d8.rs`) and the OS-reserved tables (`commands/os_reserved.rs`); the test
`keymap_doc_matches_the_registry` fails when they differ, and
`ARCHICRAFT_BLESS=1 cargo test -p archicraft-app keymap_doc` rewrites them.

## Conventions

- **Primary** is Cmd on macOS and Ctrl on Windows and Linux. File, edit, transform and reshaping
  commands use Primary with a letter, so they never fire from a letter typed into the canvas.
- **Single letters** belong to tools and view toggles only. They are off while a text field has
  focus and while a tool takes point input, where the keys go to the typed values. A second command
  on the same letter takes Shift (or Alt) with it.
- **Nothing an operating system reserves.** Every binding is checked against the tables of macOS,
  Windows and Linux (GNOME and KDE) on every host, so a build on one platform cannot ship a key
  another platform takes away.
- **Reserved before it exists.** Most D.8 commands come with later epics. Their entry names the
  roadmap epic, and their keys are reserved: no other command may take them, and once the epic
  registers the command its default keys must be exactly the reserved ones.
- The user's own keymap and its editor (UI-009) follow with archicraft-qb2.

## Decisions

- **R stays the wall reference-line cycle.** Since archicraft-5sc.1 it is a Global key of the
  plan view (it works before and while drawing a wall), so it overlaps every tool key. The roof
  takes **G** instead.
- **The window tool takes N**, because W is the wall.
- **Command palette on Primary+Shift+P**, the convention of code editors. The problems list moves
  from Primary+Shift+P to **Primary+Shift+M**, and Preferences gets **Primary+Comma**, the macOS
  convention, also used on Windows and Linux.
- **Plan/3D keeps F3 and gains Primary+3.** On a Mac keyboard F3 is a media key (Mission Control)
  and reaches the application only with Fn held.
- **Transforms follow mnemonics where Primary allows them:** move Primary+D, copy-move
  Primary+Shift+D, rotate Primary+E and mirror Primary+Shift+E (Cmd+M minimises on macOS),
  vertical move Primary+U, array Primary+Shift+A, split Primary+K and trim Primary+Shift+K, offset
  Primary+Shift+O.
- **Cut, copy and paste keep Primary+X, C and V.** egui-winit turns these keys into its clipboard
  events (`Event::Cut`, `Event::Copy`, `Event::Paste`) and sends no key event, so the shortcut loop
  never sees them: `selection-transforms` has to run the commands from the clipboard events.
- **Hide, isolate and show all are H, Shift+H and Alt+H**, as in common 3D modellers.
- Opening, stair and free-form solid share a letter with a related tool and take Shift: door D and
  opening Shift+D, slab S and stair Shift+S, measure M and free-form solid Shift+M.
